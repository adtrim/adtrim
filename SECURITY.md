# Security

Please report security problems privately, not in a public issue. Use
"Report a vulnerability" on this repository's Security tab.

Include the AdTrim version, what you did, and what happened. A sample file
helps if the problem depends on one, but do not attach personal recordings.

Only the latest release gets fixes. Update announcements are signed; see
`docs/update-notifications.md` for how AdTrim verifies them.
