AdTrim third-party license notices
==================================

The installer copies this folder next to AdTrim.exe so binary redistribution
has a stable place for dependency license notices.

Before a public installer is published, replace or supplement this placeholder
with the exact license files shipped by the bundled binary builds:

- LICENSE.FFmpeg.txt from the FFmpeg build being redistributed
- LICENSE.x264.txt or equivalent x264/GPL notice for the FFmpeg build
- LICENSE.libmpv.txt from the libmpv build being redistributed

AdTrim itself is licensed under GPLv3. See the repository LICENSE file.
